# OpenCode Installation Guide

## Option 1: Local Plugin Reference

In your `opencode.json` (or `~/.config/opencode/opencode.json`):

```json
{
  "plugin": [
    "F:/Projects/Engineer-Fusion-Skill/.opencode/plugins/engineer-fusion.js"
  ]
}
```

## Option 2: Copy to Skills Directory

Copy `skills/engineer-fusion-skill` to your OpenCode skills directory:

```bash
cp -r skills/engineer-fusion-skill ~/.config/opencode/skills/
```
